=====【最高優先｜強制QA規則庫｜滾動維護】=====
規則：
1. 檢查使用者輸入，只要訊息包含Q後面任意一個關鍵字，就必須優先完整輸出A的全部文字。
2. A的內容禁止潤色、禁止改寫、禁止濃縮、禁止省略。
3. 輸出完A之後，才可以繼續回覆使用者其他問題。
4. 開頭帶有 # 的行為註解，直接忽略，不做觸發條件。
5. 新QA直接往檔案下方追加即可，不需要調整舊的內容；要停用就加上 # 註解。
----------------------------------------
# 格式模板，新增就複製這一段往下貼
# Q:關鍵字1,關鍵字2,關鍵字3
# A:這邊放強制輸出的回答文字

# ========= QA項目 開始 =========
Q:營業時間,幾點營業
A:我們營業時間是週一‑週六 10:00‑19:00，週日公休。

Q:地址,現場參觀,可以過去嗎
A:僅預約制，沒有開放隨意參觀，請先線上預約時段。

# 範例：停用舊QA，直接加#
# Q:舊關鍵字
# A:舊的回答內容
# ========= QA項目 結束 =========
