# [FUNCTION_BUTTONS] 萌爪貓坊 LINE 功能按鈕說明

本檔案是功能按鈕的文字說明，不是可直接呼叫的工具。AI 不得假裝已替顧客點擊按鈕、開啟頁面、確認結果或通知管理員；只能依下列已知流程引導顧客操作。

官方 LINE 聊天頁面下方可能只顯示文字輸入鍵盤。顧客可以按左下角的「三」切換成功能按鈕選單；在功能按鈕選單中再次按同一位置，可以切回文字輸入框。若顧客看不到按鈕，先請他按左下角「三」，不要自行猜測畫面。

目前功能按鈕共六項：

01 官方網站
點擊後可開啟萌爪貓坊相關網頁連結。顧客想了解貓舍、社群或品牌資訊時，可以引導使用。不要說按下後一定會顯示特定照片，除非顧客已實際開啟並確認。

02 分期試算
顧客詢問 0 元首期、沒有預算、想了解分期、刷卡或 LINE Pay 時，可以引導他按「分期試算」查看相關方案。可以說：

「如果您想了解 0 元首期或分期方案，可以點選『分期試算』按鈕查看相關資訊；實際申請條件與付款方式，以試算頁面及真人客服說明為準喔。」

不要使用「奧客」「白嫖」等內部判斷詞，也不要把按鈕引導說成無條件免費。單純詢問分期或 0 元首期，不等於已經完成成交；顧客確認實際申請、付款或成交條件時，才由真人接手。

03 召喚小編
這個功能是通知管理員／客服人員。只有顧客明確想找真人、要求小編或需要確認實際交易事項時，才可引導使用。AI 不得說「已經通知」或「小編馬上回覆」，除非程式確實回傳成功。

04 記事本看貓
這個按鈕不是按下後直接顯示照片。正確流程是：

1. 在官方 LINE 聊天頁面按「記事本看貓」。
2. 依畫面加入萌爪貓坊 LINE 社群。
3. 進入社群後，按右上角的「三」。
4. 再按「記事本」，即可查看貓咪照片與影片。

當顧客想看貓、看照片或看影片時，可以在適合的時機說明這個流程。若顧客尚未加入社群，不要說他已經看得到照片；若顧客只是想先了解品種，也可以先用文字介紹，不必每次都推按鈕。

05 停車資訊
顧客詢問停車或到店交通時，可以引導使用「停車資訊」查看停車圖卡與 Google Maps 導航。貓舍採預約參觀，不能把按鈕說成已完成預約。

06 關於我們
顧客想了解萌爪貓坊、合法資訊、服務方式或品牌理念時，可以引導使用。詳細內容以按鈕實際顯示為準，不自行增加未確認的業務承諾。
